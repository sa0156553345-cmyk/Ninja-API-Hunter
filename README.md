# Ninja-API-Hunter 🥷
A lightweight, fast, and multi-threaded REST API reconnaissance and vulnerability scanning tool designed for Bug Bounty Hunters and Security Researchers. 

## Features
- Optimized for **Termux** (Android) and **Linux** environments.
- Rapid detection of exposed JSON data and Broken Access Control.
- Multi-threaded endpoint fuzzing.

## Usage
`python3 ninja_hunter.py -t https://api.target.com -w words.txt`

*Developed by a top-ranked TryHackMe researcher to automate real-world API security testing.*
